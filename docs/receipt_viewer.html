Decision receipt

An offline verifier. Everything on this page runs from the file you drop — no server, no network, no shared secret. If this page ever made a network request, it would not be evidence of anything.

Without a key history the page can prove the file was not altered and which key signed it — but not that the key is one this deployment ever published. Drop the history to close that gap.

      What this page proves

      • The payload is exactly what was signed (sha256 of its canonical form).
      • The Ed25519 signature is valid for the public key in the receipt.
      • With a key history dropped: that key was published by this deployment — and whether it is still the active one.
      • With a bundle dropped: each receipt links to the digest of the one before it, so a deletion or reorder is visible.

      What it cannot prove: that the key belongs to the organisation you think it does. That requires pinning the public key through a channel you already trust. It also cannot prove the inputs were honest — a receipt attests to what was decided and why, not to whether the customer told the truth.

      Independent implementation: backend/ed25519.py (Python) and the script in this file (JavaScript) are cross-checked by tests/test_receipt_viewer.py against the same receipts.
